# 保存到相册闪退修复 - 集成说明

## 问题

点击「保存到相册」时 App 直接闪退。

## 原因

视频 blob 在 2-20MB 之间时，JavaScript 用 `FileReader.readAsDataURL()` 把整个视频一次性转成 base64 字符串，导致 WebView 内存溢出（OOM）闪退。

## 修复内容

### 文件1：index.html（已修复）

修改了 3 处：
1. 分块保存阈值从 20MB 降到 1MB（所有 > 1MB 的视频都走分块传输，不再一次性转 base64）
2. 无分块 API 时 > 4MB 直接走下载（避免 OOM）
3. `<a download>` 阈值从 8MB 降到 4MB

### 文件2：AndroidMediaStore.kt（新增）

完整的 Kotlin 原生桥接代码，提供 5 个方法：
- `saveVideo(base64, fileName)` - 保存小视频（< 1MB）
- `startChunkedSave(fileName, mimeType)` - 启动分块会话
- `appendChunk(sessionId, base64Chunk)` - 追加分块数据
- `finalizeChunkedSave(sessionId)` - 完成保存，写入相册
- `cancelChunkedSave(sessionId)` - 取消保存

## 集成步骤

### 第1步：替换 index.html

把你项目里的 `index.html` 替换成本次修复后的版本。

### 第2步：添加 Kotlin 文件

把 `AndroidMediaStore.kt` 放到你 Android 项目的 Kotlin 源码目录中。

如果你的项目结构是这样的：
```
app/
  src/
    main/
      java/
        com/
          yourpackage/
            MainActivity.kt     ← 你的 Activity
```

就把 `AndroidMediaStore.kt` 放到同一个目录下。

注意：文件第一行的 `package com.zhengshang.zhuge` 需要改成你实际的包名。

### 第3步：在 WebView 中注册桥接

找到你设置 WebView 的代码（通常在 `MainActivity.kt` 中），添加一行：

```kotlin
// 找到你的 webView 设置代码，在 webView.settings 配置之后添加：
webView.addJavascriptInterface(AndroidMediaStore(this), "AndroidMediaStore")
```

完整示例：
```kotlin
class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        val webView = findViewById<WebView>(R.id.webView)

        // WebView 基础设置
        webView.settings.javaScriptEnabled = true
        webView.settings.domStorageEnabled = true
        webView.settings.allowFileAccess = true

        // ★ 注册保存到相册的桥接 ★
        webView.addJavascriptInterface(AndroidMediaStore(this), "AndroidMediaStore")

        // 加载页面
        webView.loadUrl("file:///android_asset/index.html")
    }
}
```

### 第4步：AndroidManifest.xml 添加权限

在 `AndroidManifest.xml` 的 `<manifest>` 标签内添加：

```xml
<!-- Android 9 及以下需要存储权限 -->
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE"
    android:maxSdkVersion="28" />
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE"
    android:maxSdkVersion="28" />
```

注意：Android 10+（API 29+）使用 MediaStore API，不需要存储权限。

### 第5步：编译测试

1. 重新编译 APK
2. 安装到手机
3. 渲染视频
4. 点击「保存到相册」
5. 应该看到 Toast 提示「视频已保存到相册」

## 如果你的项目不是原生 Android

### 如果是 uni-app (HBuilderX)

不需要 Kotlin 文件。在 `manifest.json` → App 模块配置 → 权限配置中确保开启了存储权限，然后在代码中使用 `plus.gallery.save()` API。

修复后的 index.html 中 `_saveToAlbumPlus()` 函数已经处理了这种情况。

### 如果是 Tauri (PakePlus)

不需要 Kotlin 文件。确保 Tauri 的 `fs` 插件已安装：

```bash
# 在项目目录执行
npm install @tauri-apps/plugin-fs
```

修复后的 index.html 中 `_saveViaTauri()` 函数会自动使用 Tauri 的文件系统 API 保存视频到下载目录。

## 验证修复是否生效

打开 App 的 WebView 调试控制台，渲染视频后点击保存，观察日志：

### 成功的日志（分块模式）：
```
[SAVE-MS] Using chunked transfer (blob=12.5MB >= 1MB)
[SAVE-MS-CHUNK] START: blob=12.5MB, chunks=7, file=AI智能成片_1080P_xxx.webm
[SAVE-MS-CHUNK] Progress: 28% (2/7)
[SAVE-MS-CHUNK] Progress: 57% (4/7)
[SAVE-MS-CHUNK] Progress: 100% (7/7)
[SAVE-MS-CHUNK] Finalizing save...
[SAVE-MS-CHUNK] ✅ SUCCESS
```

### 如果看到这条日志说明没有原生桥接：
```
[SAVE-V8] ⚠️ window.AndroidMediaStore not available
```
需要按上面的步骤集成 Kotlin 代码。
