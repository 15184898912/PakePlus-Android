# 即梦AI中文版 - 纯静态Web版本

这是一个纯HTML/CSS/JS版本，可以直接在浏览器打开，也可以直接用PakePlus打包成APK。

## 🚀 使用方法

### 方法一：直接在浏览器预览
直接双击 `index.html` 文件，即可在浏览器中打开预览。

### 方法二：PakePlus打包（推荐）
1. 打开 PakePlus 桌面应用
2. 点击「新建项目」
3. 「网站地址」选择「本地文件」，然后选择本目录下的 `index.html` 文件
   - 或者选择整个文件夹作为资源目录
4. 按照以下配置填写：
   - **APP名称**：即梦AI中文版
   - **APP标识**：com.jimeng.ai
   - **APP版本**：1.0.0
   - 图标可使用在线生成或自行准备512x512 PNG
5. 权限勾选：访问网络、下载文件、文件相册、相机摄像
6. 点击「预览」即可看到效果
7. 点击「发布」打包生成APK

### 方法三：本地HTTP服务器
```bash
# 在本目录下启动服务器
python3 -m http.server 8080
# 然后浏览器访问 http://localhost:8080
```

## 📱 功能说明

- **首页**：快捷入口、热门风格、最近作品
- **创作页**：文生图/图生图、提示词输入、灵感助手、参数调节
- **画廊页**：作品瀑布流展示、收藏功能
- **个人中心**：API密钥配置、主题切换、缓存清理、设置
- **提示词助手**：内置模板和标签组合系统
- **深色/浅色主题**：支持主题切换
- **本地存储**：作品记录、API密钥保存在浏览器localStorage

## ⚙️ API配置

在「我的」→「API密钥配置」中填入您的即梦AI API密钥即可使用。

> 注：当前为演示版本，生成图片使用 picsum.photos 随机图片服务。接入真实API时请修改 `js/app.js` 中的 `generateImage()` 函数，替换为真实API请求即可。
